# FK Wallet — Python Telegram bot

Отдельный long-polling процесс для существующего @FK_WALLEET_BOT. Новый бот в BotFather и новый токен не нужны. Node.js сервер продолжает обслуживать Mini App и платежи.

Переменные на Bothost:

- `BOT_TOKEN`: тот же токен Telegram-бота, что у Node.js приложения.
- `MINI_APP_URL`: `https://fk-wallet-kuska12301.bothost.tech/mini-app`.
- `BOT_STATE_PATH`: `./data/telegram-bot.sqlite` (постоянный диск).
- `PYTHONUNBUFFERED`: `1`.

Создайте отдельный сервис Python 3.11 или новее с тем же Git-репозиторием, веткой main и точкой входа `bot/main.py`. Отключите домен и использование корневого Dockerfile (он предназначен для Node.js Mini App). Сторонних зависимостей нет.

Запуск: `python bot/main.py`. Тесты: `python -m unittest discover -s bot -p test_bot.py`.

На `/start` приходит приветствие с web_app-кнопкой «Открыть FK Wallet». Также устанавливается кнопка меню бота. Кнопка открывает Mini App от того же бота, поэтому сервер проверяет исходную Telegram-подпись. Платёжная логика и токен Crypto Pay в Python-процессе отсутствуют.

Должен работать только один polling-процесс на токен. Если настроен Telegram webhook, процесс остановится, не удаляя его. Смещение обновлений сохраняется в SQLite; старые команды более пяти минут до запуска пропускаются. При аварии между отправкой приветствия и сохранением смещения возможно повторное приветствие; финансовые операции здесь не выполняются.
